# Feature Implementation

## Purpose

Define the workflow for delivering end-to-end features in Bobslab.

## Workflow

1. **Understand**: Clarify requirements and constraints.
2. **Discover**: Check existing utilities, hooks, tokens, and components before writing new ones.
3. **Plan**: Propose changes respecting package boundaries.
4. **Implement**: Implement minimal, high-cohesion code.
5. **Test**: Add unit and integration tests.
6. **Validate**: Run type checks, linting, tests, and build.
