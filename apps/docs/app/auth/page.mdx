## `AuthManager`

`AuthManager` is a singleton coordinating token refresh operations, browser session caching, cross-tab synchronization, and header injection.

### 1. In-flight Refresh Deduplication

Prevents concurrent duplicate refresh requests across multiple tabs or API calls:

```ts
import { authManager } from "@bobslab/auth";

authManager.setRefreshHandler(async () => {
  const res = await fetch("/api/auth/refresh", { method: "POST" });
  if (!res.ok) return null;
  return await res.json();
});

// Components or HTTP interceptors call:
const tokens = await authManager.refreshToken();
```

### 2. Session Resolving & Caching

Caches active browser sessions with in-flight deduplication to prevent redundant backend round-trips:

```ts
import { authManager } from "@bobslab/auth";

authManager.setSessionResolver(async () => {
  const res = await fetch("/api/auth/session");
  if (!res.ok) return null;
  return await res.json();
});

const session = await authManager.getSession();
```

### 3. Request Header Application

Automatically applies `Authorization: Bearer <accessToken>` and `X-Refresh-Token` headers to outgoing fetch or Axios request configs:

```ts
const requestConfig = {
  headers: { "Content-Type": "application/json" }
};

await authManager.applyAuthTokenToReq(requestConfig);
// requestConfig.headers now includes Authorization and X-Refresh-Token
```

### 4. Cross-Tab Sync & Lifecycle Events

Listen to authentication lifecycle events (`login`, `logout`, `refresh`) and synchronize tokens across browser tabs:

```ts
// Subscribe to auth events
authManager.on("login", (tokens) => {
  console.log("Logged in:", tokens);
});

authManager.on("logout", () => {
  console.log("Logged out, redirecting...");
});

// Sync cross-tab events in browser
if (typeof window !== "undefined") {
  window.addEventListener("storage", (e) => authManager.handleStorageEvent(e));
}
```

## JWT Claim Decoder

Extract user payload claims and inspect expiration status with safety buffer:

```ts
import { decodeJwtClaims, isTokenExpired } from "@bobslab/auth";

const claims = decodeJwtClaims(accessToken);
const expired = isTokenExpired(accessToken, 30); // 30s buffer
```
