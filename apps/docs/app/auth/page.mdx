## `AuthManager`

Coordinates in-flight token refresh operations to prevent concurrent duplicate refresh requests across multiple tabs or API calls:

```ts
import { authManager } from "@bobslab/auth";

authManager.setRefreshHandler(async () => {
  const res = await fetch("/api/auth/refresh", { method: "POST" });
  return await res.json();
});

// Components or interceptors call:
const tokens = await authManager.refreshToken();
```

## JWT Claim Decoder

Extract user payload claims and inspect expiration status with safety buffer:

```ts
import { decodeJwtClaims, isTokenExpired } from "@bobslab/auth";

const claims = decodeJwtClaims(accessToken);
const expired = isTokenExpired(accessToken, 30); // 30s buffer
```
