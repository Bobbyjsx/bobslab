# Table

Composable, accessible table components with row selection, sorting indicators, soft row highlight, and semantic layout.

## Usage

```tsx
import {
  Table,
  TableHeader,
  TableBody,
  TableRow,
  TableHead,
  TableCell,
  TableCheckbox,
} from "@bobslab/ui";

export function ExampleTable() {
  const [selected, setSelected] = React.useState(false);

  return (
    <Table>
      <TableHeader>
        <TableRow>
          <TableHead className="w-12">
            <TableCheckbox checked={selected} onChange={() => setSelected(!selected)} />
          </TableHead>
          <TableHead isSorted="asc">Service Name</TableHead>
          <TableHead>Price</TableHead>
        </TableRow>
      </TableHeader>
      <TableBody>
        <TableRow selected={selected}>
          <TableCell>
            <TableCheckbox checked={selected} onChange={() => setSelected(!selected)} />
          </TableCell>
          <TableCell className="font-medium">Setup & Configuration</TableCell>
          <TableCell>$200.00</TableCell>
        </TableRow>
      </TableBody>
    </Table>
  );
}
```

## Subcomponents Reference

| Component | Description |
| :--- | :--- |
| `<Table>` | Root table container element with responsive borders and rounded corners. |
| `<TableHeader>` | Table header wrapper element (`<thead>`). |
| `<TableBody>` | Table body wrapper (`<tbody>`) with row divider lines. |
| `<TableRow>` | Row component supporting `selected={boolean}` and `data-state="selected"`. |
| `<TableHead>` | Header column cell supporting sorting indicator (`isSorted="asc" \| "desc"`). |
| `<TableCell>` | Standard tabular body content cell (`<td>`). |
| `<TableCheckbox>` | Custom styled checkbox tailored for multi-row batch selection. |

> For dataset pagination, explore the standalone [`Pagination`](/pagination) component.
