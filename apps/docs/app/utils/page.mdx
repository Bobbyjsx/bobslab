## `AmountAction` Currency Utilities

`AmountAction` resolves real-world currency discrepancies across international and regional storefronts by cross-referencing ISO codes, contextual coupon text, regional hints, and merchant domain TLDs.

### 1. Infer Currency from Mixed Context

```ts
import { AmountAction } from "@bobslab/utils";

// Resolves discrepancies when raw currency is "$" but coupon mentions Nigeria or .ng
const currency = AmountAction.inferCurrency({
  currency: "USD",
  text: "2k Off When You Shop Up to 20k and Above. Extra discount for orders over 20,000 NGN.",
  countryOrRegion: "Nigeria",
  domain: "jumia.com.ng"
});
// => "NGN"
```

### 2. Format Discount Header

Formats discount callout text for deal cards and badges:

```ts
AmountAction.formatDiscount({
  discountType: "amount",
  discountValue: 2000,
  currency: "NGN",
  region: "Nigeria"
});
// => "₦2,000 OFF"

AmountAction.formatDiscount({
  discountType: "percent",
  discountValue: 20
});
// => "20% OFF"

AmountAction.formatDiscount({
  discountType: "shipping"
});
// => "FREE SHIPPING"
```

### 3. Format Minimum Order

```ts
AmountAction.formatMinimumOrder(20000, "NGN");
// => "Min. order ₦20,000"
```

### 4. Format Amount & Currency

```ts
AmountAction.formatAmountAndCurrency("NGN", 250000);
// => "₦250,000"

AmountAction.formatAmountAndCurrency("USD", 49.99);
// => "$49.99"
```

### 5. Kobo & Naira Conversions

```ts
AmountAction.koboToNaira(250000); // 2500
AmountAction.nairaToKobo(2500);   // 250000
```

## Core Functions

### `cn`

Merges Tailwind CSS classes reliably using `clsx` and `tailwind-merge`:

```ts
import { cn } from "@bobslab/utils";

const className = cn("p-4", isPrimary && "bg-primary text-primary-foreground");
```

### `formatCurrency`

Formats numerical values into localized currency strings with symbol placement:

```ts
import { formatCurrency } from "@bobslab/utils";

formatCurrency(2500, "USD"); // "$2,500.00"
formatCurrency(250000, "NGN"); // "₦250,000.00"
```

### `formatSize`

Converts raw byte integers into human-readable data quantities:

```ts
import { formatSize } from "@bobslab/utils";

formatSize(1048576); // "1 MB"
formatSize(52428800); // "50 MB"
```

### `keysToCamel` & `keysToSnake`

Deeply transforms JSON payload keys between `camelCase` and `snake_case`:

```ts
import { keysToCamel, keysToSnake } from "@bobslab/utils";

const client = keysToCamel({ user_id: 123, created_at: "2026-10-22" });
// { userId: 123, createdAt: "2026-10-22" }
```
