# Utilities (`@bobslab/utils`)

Core utility functions for class concatenation (`cn`), case transformation, financial math, and currency formatting.

## Functions

### `cn`

Merges Tailwind CSS classes reliably using `clsx` and `tailwind-merge`:

```ts
import { cn } from "@bobslab/utils";

const className = cn("p-4", isPrimary && "bg-primary text-primary-foreground");
```

### `formatCurrency`

Formats numerical values into localized currency strings with symbol placement:

```ts
import { formatCurrency } from "@bobslab/utils";

formatCurrency(2500, "USD"); // "$2,500.00"
formatCurrency(250000, "NGN"); // "₦250,000.00"
```

### `formatSize`

Converts raw byte integers into human-readable data quantities:

```ts
import { formatSize } from "@bobslab/utils";

formatSize(1048576); // "1 MB"
formatSize(52428800); // "50 MB"
```

### `keysToCamel` & `keysToSnake`

Deeply transforms JSON payload keys between `camelCase` and `snake_case`:

```ts
import { keysToCamel, keysToSnake } from "@bobslab/utils";

const client = keysToCamel({ user_id: 123, created_at: "2026-10-22" });
// { userId: 123, createdAt: "2026-10-22" }
```
