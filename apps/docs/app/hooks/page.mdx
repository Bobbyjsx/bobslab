## Available Hooks

### `useDebounce`

Delays updating a state value until a specified timeout has elapsed since the last change:

```tsx
import { useDebounce } from "@bobslab/hooks";

const debouncedQuery = useDebounce(searchQuery, 300);
```

### `useCountdown`

High-precision countdown timer with start, stop, and completion callback:

```tsx
import { useCountdown } from "@bobslab/hooks";

const { countdown, isRunning, start, reset } = useCountdown({
  seconds: 60,
  autoStart: true,
  onComplete: () => console.log("Time up!"),
});
```

### `useClipboard`

Safely writes text to the user's clipboard with configurable reset duration:

```tsx
import { useClipboard } from "@bobslab/hooks";

const { copied, copy } = useClipboard({ timeout: 2000 });
```

### `useLocalStorage`

SSR-safe synchronized state stored in browser `localStorage`:

```tsx
import { useLocalStorage } from "@bobslab/hooks";

const [theme, setTheme] = useLocalStorage("app-theme", "system");
```

### `useIsMobile`

Real-time responsive breakpoint listener:

```tsx
import { useIsMobile } from "@bobslab/hooks";

const isMobile = useIsMobile(768);
```
