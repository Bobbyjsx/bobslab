## Prompt Tag Codecs

Encode and decode tags in prompt templates (e.g. `[prompt:id|title|b64]`):

```ts
import { formatPromptTag, parsePromptTags, tokenizePromptText } from "@bobslab/ai";

const tag = formatPromptTag({
  id: "security-audit",
  title: "Security Audit",
  prompt: "Verify input validation and JWT verification invariants.",
});

const { cleanText, tags } = parsePromptTags(`Run ${tag} on commit.`);
```

## Streaming & SSE Parsers

Parse incoming streams from OpenAI, Anthropic, or custom FastAPI endpoints:

```ts
import { parseSseBlock, parseEventPayload, sanitizeStreamErrorText } from "@bobslab/ai";

const block = parseSseBlock(rawSseChunk);
if (block) {
  const payload = parseEventPayload(block.data);
}
```
