# Icon Primitives (`@bobslab/icons`)

Accessible, scalable SVG icon primitives designed for high-density developer tools and modern user interfaces.

## Installation

```bash
pnpm add @bobslab/icons
```

## Usage

```tsx
import {
  Logo,
  SpinnerIcon,
  CheckIcon,
  CopyIcon,
  CloseIcon,
  SearchIcon,
  ChevronDownIcon,
} from "@bobslab/icons";

export function Example() {
  return (
    <div className="flex items-center gap-3">
      <Logo size={24} />
      <SearchIcon size={18} className="text-muted-foreground" />
      <CheckIcon size={18} className="text-emerald-500" />
    </div>
  );
}
```

## Props Reference

Every icon accepts `IconProps`:

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `size` | `number \| string` | `18` | Rendered width and height in pixels. |
| `className` | `string` | `""` | Additional CSS class names. |
| `color` | `string` | `"currentColor"` | Fill or stroke color value. |
| `title` | `string` | — | Accessible title attribute for screen readers. |
