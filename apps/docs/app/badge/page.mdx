# Badge

Compact visual indicator representing status, tags, counts, and categories.

import { BadgeDemo } from '@/components/BadgeDemo';

## Interactive Preview

<BadgeDemo />

## Usage

```tsx
import { Badge } from "@bobslab/ui";

export function Example() {
  return (
    <div className="flex gap-2">
      <Badge variant="default">Default</Badge>
      <Badge variant="neutral">Neutral</Badge>
      <Badge variant="success">Success</Badge>
      <Badge status="completed">Completed</Badge>
      <Badge status="failed">Failed</Badge>
    </div>
  );
}
```

## Props Reference

### `<Badge>`

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `variant` | `"default" \| "success" \| "warning" \| "info" \| "danger" \| "neutral" \| "tier"` | `"default"` | Visual style preset. |
| `status` | `"completed" \| "processing" \| "pending" \| "failed" \| "cancelled"` | — | Domain-level status color variant with dot indicator. |
| `className` | `string` | `""` | Additional styling classes. |
| `children` | `React.ReactNode` | — | Text label or content. |
